# APEX Basketball Academy — v7

Site vitrine responsive pour l'académie APEX Basketball Academy.

## Mise à jour v7
- Bouton **Contactez-nous** dans la navigation, relié à `mailto:pnounjo@gmail.com`.
- L'image `assets/apex-hero-athletes.png` est conservée telle quelle sur ordinateur.
- Sur smartphone (<= 600px), l'image du hero devient un élément du flux et se place **sous** `.hero-content` au lieu de passer au-dessus du texte.
- Formulaire HTML APEX connecté au Google Form via les identifiants `entry.*` déjà configurés.

## Structure

- `styles.css` : design responsive
- `script.js` : envoi du formulaire vers Google Forms
